## Coverage and evidence rules

- Reviewed the July 22, August 5, and August 26 boards for carryovers. Astra now has a public rollout; GLM-5.3 now has weights; Fable/Mythos, Gemini and Muse have new versions; Ling adds Fin/VL variants. Mistral OCR adds GA. Granite MLX is a deployment update, not a new base model.
- Searched official release documentation, model cards, repositories and launch posts across text/reasoning/coding, vision/image/video/world models, speech, OCR, embeddings, agents, driving and financial time series. HF publisher inventory included Qwen, Z.ai, DeepSeek, Tencent, InclusionAI, NVIDIA, Microsoft, Liquid AI, Cohere, StepFun, Lightricks, Wan, Black Forest Labs, ByteDance Seed, MiniMax, Moonshot, OpenBMB, Baidu, Xiaomi, IBM, LG and Ant International; IFM, Thesys and Pipecat were followed from launch sources.
- Checked downloadable weight artifacts and license metadata rather than treating repository creation as release. Dates explicitly marked “upload” are artifact evidence, not inferred announcement dates. An official model card without an X post remains a valid source.
- Used local Grok to locate original X posts, then independently read selected posts through the public FxTwitter mirror. Numeric canonical X URLs are embedded. Kept the organizer’s K2 builder post and Arena image rankings as attributed commentary.
- Primary sources resolve conflicting dates: Mistral’s changelog says August 31 GA; Sonic-3.6’s official blog and X say August 27; ChatGPT Images 2.5 launched September 8. Deepgram’s September 2 X announcement and September 3 changelog describe different language-update batches. Do not conflate them.
- This is a broad verified roundup of relevant releases in the window, not a claim to enumerate every community fine-tune, quantization, API alias or silent update. Official Granite MLX packaging is included for its direct local-deployment relevance; arbitrary repacks are not separately counted.

## Exclusions and unresolved leads

- UI-Venus-2-9B: public files exist, but its model card says the weight license is pending confirmation. Excluded from the release slides until that is resolved.
- Qwen-MT-Image 2.0: official API documentation exists, but an in-window launch date was not established. Excluded from this dated roundup.
- Unconfirmed Qwen API snapshot leads: no verified material release delta; excluded.
- Ink-2, Grok 4.6, Muse Glimmer, Muse Image, Wan 3, Nemotron 3.5 Lightning, Qwen3.8 base releases and H3 Max: older launches or already covered; not counted again without a verified material delta. Granite 4.2’s base launch is likewise not new.
- The internal OpenAI math system is a separate research Topic, not a publicly released Astra variant. Benchmark rankings and throughput figures remain author/provider measurements.
