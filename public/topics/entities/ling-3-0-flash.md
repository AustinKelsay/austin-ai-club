# Ling-3.0-flash

Ling-3.0-flash is Ant Group / InclusionAI's 124B hybrid-reasoning MoE with about 5.1B active parameters per token, positioned for production-scale agent workloads.

September 2026 adds the MIT-licensed Fin specialization and VL vision-language variant. The Fin card lists 124B total/5.1B active parameters; VL lists 124B/5.5B active and publishes BF16/FP8 weights. These are separate variants of the earlier Flash release.
