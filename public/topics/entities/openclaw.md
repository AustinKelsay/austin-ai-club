# OpenClaw

OpenClaw is a recurring Sovereign AI Club entity because it anchors several coding-agent, local-agent, ecosystem-drama, and customization threads.

OpenClaw Enterprise was announced September 29, 2026 as an MIT-licensed control plane for persistent agents on an organization's own infrastructure. Originating at OpenAI and donated to the OpenClaw Foundation, it was developed with Red Hat and NVIDIA. The project is intended for internal pilots before its planned 1.0 release; self-hosted orchestration does not by itself mean local model inference.
