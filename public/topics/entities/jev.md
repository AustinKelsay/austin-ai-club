# Jev

Jev is TypeSafe AI's hosted System One decision model. Applications supply state and typed questions; it returns choices, scores and probabilities rather than generated prose. TypeSafe presents calibration as a core feature. Schema validity does not guarantee a correct decision, and the published speed and cost comparisons are vendor evaluations.

Builder demos use Jev for bounded game actions, steering choices in a browser driving simulator, browser actions from partial speech transcripts, call-outcome forecasting and live sentiment scoring. Their surrounding software supplies candidate actions and executes them. The Minecraft demo also uses Astra for planning; the receptionist experiment uses call structure without audio or transcripts.

Kev, DiffusionGemma serving and SGLang demonstrate open implementations of a similar decision interface. API compatibility alone does not establish equivalent calibration or quality.
