### Security
- **Claude Code source leaked via npm sourcemap** - Chaofan Shou says `@anthropic-ai/claude-code@2.1.88` shipped a `cli.js.map` in the npm tarball, exposing the bundled source. Sigrid Jin mirrored it to GitHub. More interesting than the drama: the map gives a view into [[Claude Code]] and Anthropic's internal [[Coding Agents]] fast paths and feature flags around bridge mode, daemon workers, remote control, and self-hosted runners

  Post: https://x.com/StraughterG/status/2039117804155068903

  Source: https://x.com/karpathy/status/2036487306585268612

- **Axios supply-chain attack** - [[Andrej Karpathy|Karpathy]] flags a live npm compromise of `axios`, saying the dangerous part is not just one bad publish but how unpinned dependencies let a brief malicious release spread randomly at scale. The quoted context says `axios@1.14.1` pulled in a newly published `plain-crypto-js@4.2.1`
  Post: https://x.com/karpathy/status/2038849654423798197
